# Ecossistema interno — Projeto Integrador

Este diretório contém a habilidade pedagógica, o catálogo de materiais de apoio, a rubrica de aprovação e o fluxo Mermaid do Projeto Integrador. A decisão final de aprovação permanece com o professor.

## Pacote

- `SKILL.md`: habilidade reutilizável para planejar, acompanhar e avaliar.
- `materiais/KIT_MATERIAIS_APOIO_AVALIATIVOS_2026.md`: catálogo semanal de materiais, produtos, evidências e habilidades EM13CO.
- `avaliacao/RUBRICA_APROVACAO_PROJETO_INTEGRADOR.md`: rubrica analítica de aprovação.
- `fluxos/FLUXO_AUTOMACAO_PROJETO_INTEGRADOR.mmd`: fluxo interno de geração, revisão, armazenamento e versionamento.
