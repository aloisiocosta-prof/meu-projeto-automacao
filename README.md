# meu-projeto-automacao
Repositório configurado com CI/CD e governança.

## 🛠 Padrões de Desenvolvimento
- **Fluxo**: Gitflow (develop -> main).
- **Commits**: Conventional Commits (feat, fix, chore, ci).
- **Pull Requests**: Obrigatório vincular a Issue na descrição (ex: `Closes #1`).
- **Qualidade**: Linting (Biome), Commitlint, Knip.
- **Observabilidade**: Sentry / New Relic.
- **Testes**: Unitários, Integração e E2E (Playwright) com cobertura no Codecov.
